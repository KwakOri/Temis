# 단계별 개발 실행 명령문

최종 수정: 2026-08-04

이 폴더의 문서는 사용자 템플릿 UI 통합 계획을 단계별 개발 작업으로 지시하기
위한 복사·붙여넣기용 명령문이다.

## 사용 원칙

1. `00`부터 순서대로 실행한다.
2. 각 단계는 별도 Codex 작업에서 실행해도 된다.
3. 새 작업에는 해당 단계 명령문 전체를 전달한다.
4. 작업자는 선행 단계의 완료 상태를 문서와 코드에서 확인해야 한다.
5. `00`~`07` 명령문은 원격 Supabase 읽기·쓰기를 허용하지 않는다.
6. `08` 명령문도 먼저 읽기 전용 재감사만 수행하며, 원격 쓰기는 별도의 명시적
   승인을 받은 뒤에만 수행한다.
7. 단계 완료 시 구현뿐 아니라 해당 단계 문서와 상위 README의 상태·검증 결과도
   갱신한다.

0. [현재 상태 재검증과 결정 기준선 확정](./00-command.md)
1. [로컬 DB·API 개발 기준선 구축](./01-command.md)

4. [관리자 카탈로그 대표 이미지 업로드 구현](./04-command.md)
5. [상점·상품 종류별 UX 구현](./05-command.md)

각 명령문은 작업 범위를 임의로 다음 단계까지 넓히지 않도록 작성됐다. 단계에서
발견한 후속 작업은 현재 단계의 완료 조건을 막는지 구분해 기록하고, 막지 않는
항목은 다음 단계 또는 별도 백로그로 넘긴다.
