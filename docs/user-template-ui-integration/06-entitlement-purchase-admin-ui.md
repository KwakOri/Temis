# 06. 권한·구매·관리자 연결 UI

상태: 대기  
선행 조건: 05단계 상점·상품 흐름

## 1. 목표

구매 승인, 맞춤 템플릿 직접 부여, 작가 연결이 모두 같은 사용자 템플릿 목록과
런타임 entitlement로 이어지게 하고 관리자가 종류를 혼동하지 않게 한다.

## 2. 공통 entitlement

권한 판정 순서를 유지한다.

```text
로그인
→ 관리자 여부
→ published 상태
→ template_access 존재
→ template_artists 연결 여부
→ 허용 또는 거부
```

`is_public`이나 상점 노출 여부는 이미 권한을 가진 사용자의 실행 판정에 사용하지
않는다.

## 3. 관리자 접근 권한 화면

템플릿 선택 카드에 다음 정보를 추가한다.

- 시간표/썸네일
- Legacy/Studio
- draft/published/archived
- 일반 판매/맞춤

기본 필터:

- 이름 검색
- 종류
- 게시 상태

draft나 archived에 권한을 미리 부여하는 운영이 필요할 수 있으므로 API에서
무조건 차단하지는 않는다. 대신 일반 사용자는 published 전까지 실행할 수 없다는
상태를 관리자 UI에 명확히 표시한다.

## 4. 직접 권한 부여

직접 부여 API는 다음 성질을 가져야 한다.

- 같은 `(template_id, user_id)` 요청에 idempotent
- 존재하지 않는 사용자·템플릿 거부
- `templatePlanId`가 제공되면 해당 템플릿 상품 plan인지 검증
- 요청 body의 `granted_by`를 신뢰하지 않고 인증 관리자 id 사용
- 성공 후 권한 목록과 사용자 템플릿 query 갱신

DB unique 충돌을 500으로 노출하지 않고 기존 권한 갱신 또는 명확한 409로
처리한다. 초기 권장 동작은 upsert다.

## 5. 권한 레벨 UI

현재 사용자 런타임은 access level에 따른 기능 차이를 제공하지 않는다.

- 관리자 화면에서는 DB 값 `read/write/admin`을 확인·수정할 수 있다.
- 일반 사용자 화면에서는 구조 편집 가능으로 오해할 표현을 사용하지 않는다.
- access level을 실제 Studio 구조 편집 권한에 연결하는 작업은 별도 범위다.

## 6. 구매 승인 UI

관리자 구매 요청 목록에 다음 정보를 표시한다.

- 템플릿 이름
- 시간표/썸네일
- Legacy/Studio
- plan과 가격
- 요청 사용자
- pending/completed/rejected 상태

승인 버튼은 서버의 원자적 승인 route만 호출한다. 클라이언트에서 권한 insert와
상태 update를 두 번 호출하지 않는다.

중복 승인 시 동일 권한 한 건을 유지하고 성공 또는 이미 완료 상태를 명확히
표시한다.

## 7. 작가 연결

- `template_artists` 연결 사용자는 마이페이지의 내 작업물에 나타난다.
- 구매 권한도 동시에 있으면 내 작업물 쪽만 표시하는 현재 중복 규칙을 유지한다.
- 작가 연결 해제 후 직접 구매 권한이 남아 있으면 구매한 템플릿으로 다시 나타나야
  한다.
- 작가 연결 mutation 후 사용자 템플릿 query invalidation 경계를 확인한다.

## 8. 회수와 상태 변경

- 직접 권한 회수 후 새 런타임 요청은 403이어야 한다.
- 열려 있던 브라우저 화면은 다음 API 요청 또는 새로고침에서 권한 상실을
  처리해야 한다.
- 템플릿이 archived가 되면 권한 행은 유지하더라도 일반 사용자 목록과 실행에서
  제외한다.
- 판매 중지와 기존 구매자의 이용 권한은 별개로 유지한다.

## 9. 완료 조건

- [ ] 관리자 권한 화면에서 세 템플릿 종류를 구분할 수 있다.
- [ ] 직접 권한 부여가 idempotent하다.
- [ ] 구매 승인이 권한과 요청 상태를 원자적으로 변경한다.
- [ ] 일반 사용자 UI가 access level을 구조 편집 권한으로 오해시키지 않는다.
- [ ] 작가/구매 중복과 연결 해제 후 fallback이 검증된다.
- [ ] 회수·archive·판매 중지의 서로 다른 의미가 유지된다.
